## 📌 About

This repository documents my C++ learning journey. Programs are organized into topic folders, each with its own README. Every folder targets a specific concept and builds on what came before — from basic functions and strings to polymorphism, templates, smart pointers, and STL.

---

## 📂 Structure

### 🧱 [Basics](Basics/)
Five progressive programs covering C++ fundamentals — functions, string operations, function overloading, vectors, and dynamic memory with raw pointers.

### 🔤 [Strings](Strings/)
String manipulation using `string` methods, lambdas, character functions, and frequency analysis.

### 🏛️ [Classes](Classes/)
Thirteen focused programs covering the full OOP spectrum — constructors, encapsulation, access specifiers, copy constructors, friend functions, inheritance, polymorphism, and class templates.

### ⚠️ [ExceptionHandling](ExceptionHandling/)
Custom exception classes with structured `try/catch` error handling in a bank account simulation.

### 📅 [Files&Date/Date](Files&Date/Date/)
Date and time handling with `ctime` and `chrono` — formatting, arithmetic, and execution timing.

### 📁 [Files&Date/Files](Files&Date/Files/)
File-based persistence with OOP — saving/loading plain structs and polymorphic inventory objects using type-tag serialization.

### 🧠 [SmartPointers](SmartPointers/)
Two programs exploring `unique_ptr`, `shared_ptr`, `weak_ptr`, and move semantics.

### 📦 [STL](STL/)
STL containers and algorithms — `map`, `set`, `unordered_map`, lambdas, and `vector<pair>` for text and data processing.

### 🗂️ [Projects](Projects/)
Includes various projects coded in C++.

## 🔧 How to Compile & Run Any File

**Requirements:** GCC/G++ with C++11 or later

```bash
# Compile
g++ filename.cpp -o output

# Run (Linux / macOS)
./output

# Run (Windows)
output.exe
```
